Weapon Skin/Glam v2
Heavylog8

Player keeps the stats of the equipped weapon and overrides its on screen model with a different weapon they own. Set/unset from the in-game weapon menu.

Mod comes in 2 versions: patch or lua/UE4SS. Only install ONE version at time.

This is the LUA/UE4SS version. Use this version if you install other patch mods that change character stats, levels, level up attributes, etc. This version ensures maximum compatibility. 

Its mostly identical to the patch version, except this version will not remember your chosen skins when you load a game, so youll need to re equip them whenever you load a save file.


TROUBLESHOOTING:

**This mod has been tested with UE4SS builds 3.0.1-848-g91b70e5 (Jan 2026) to 3.0.1-1136-g35d1795d (Sept 2026). It should have extremely high compatibility across this period and in future releases. 

**If you use save state editor to add things to your save file, this mod may not be compatible. Save state edits are unpredictable; if your game crashes after you install this mod, its likely because you used an editor.
