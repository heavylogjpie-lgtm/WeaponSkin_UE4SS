Weapon Skin/Glam  -  v2
Heavylog8

Player keeps the stats of the equipped weapon and overrides its on screen model
with a different weapon they own. Set from the weapon menu.

Mod comes in 2 versions: patch or lua/UE4SS. Only install ONE version at time.

This is the LUA/UE4SS version. Use this version if you install other patch mods that change character stats, levels, level up attributes, etc. This version ensures maximum compatibility. 

Its mostly identical to the patch version, except this version will not remember your chosen skins when you load a game, so youll need to re equip them whenever you load a save file.

See changelog.txt for what changed in v2.

TROUBLESHOOTING:

**If you use save state editor to add things to your save file, this mod may not be compatible. Save state edits are unpredictable; if your game crashes after you install this mod, its 99% because you used an editor. Please dont flame my comments page unless you first confirm this isn't the issue.

**I have been writing lua for awhile now. To the best of my ability, I ensure they are as lean as possible. This mod will not cause any performance hampering/stuttering, etc. Logging is the bare minimum, debug is off by default and in all cases only runs the minimum needed for emergency troubleshooting. If you prefer that gone you can remove by whatever means youre comfortable with.

I have tested both versions extensively, they are working and stable so please check the above carefully before leaving any comments requesting help. If genuine bug is found, DM me and ill check it out ASAP.
