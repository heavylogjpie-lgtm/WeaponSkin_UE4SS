v3:

Keyboard now uses V, which is not used by any other CommonUI action. The prompt shows (V) on keyboard; controller is unchanged.

v2:

Fixed a hard crash on the newest experimental UE4SS builds. Pressing Equip/Remove in the weapon menu killed the game instantly. Older UE4SS builds were unaffected

Issue traced to mod reading the skin reference off the weapon at runtime. Latest UE4SS build changed how that kind of reference is stored internally. v2 no longer reads it at all. Skin paths now come from a list built from the game's own weapon data.

On request, added two Verso weapons to list, Velokan and Mitigated Perfection. Neither is obtainable in vanilla and even if you mod them to be obtainable they only use Versos default skin. But if you still want to, they should now behave like any other weapon, with the caveat that I haven't tested that personally
