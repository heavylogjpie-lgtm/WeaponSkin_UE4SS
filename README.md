WeaponSkin_UE4SS  (v2)
======================

Requires UE4SS. Copy this folder to:

  <game>/Sandfall/Binaries/Win64/ue4ss/Mods/WeaponSkin_UE4SS

Keep a weapon's stats, override its model with another weapon you own.

Do not install with WeaponSkin_Patch.

See readme.txt for player notes and changelog.txt for what changed in v2.

DEBUG is the first line of Scripts/main.lua.
